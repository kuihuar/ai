## 二、必备技能

### Go 语言

- 熟练掌握 **goroutine**、**channel**、**interface** 等核心特性
- 深入理解 **内存模型**、**GC**、并发模式（`sync` / **errgroup** / **singleflight** / **context**）
- 熟悉性能调优工具：**pprof**、**trace**、**race detector**

### Web & 协议

- 熟练使用 **Hertz**（CloudWeGo）或 **Gin**；熟悉 **RESTful**、**WebSocket**
- 了解 **gRPC** / **Protobuf**

### 数据库

- **MySQL**：SQL 优化、索引、事务、锁机制
- **MongoDB**：基本操作与聚合；**GORM**（Hook、预加载、事务）— 详细说明见 [mongodb-gorm-guide.md](./mongodb-gorm-guide.md)

### 缓存 & 消息队列

- **Redis**：核心数据结构、Cluster、分布式锁、缓存策略
- **Kafka** 基本概念；**Asynq** 异步任务队列优先

### 基础设施

- **Docker** 多阶段构建；**Kubernetes** 基本概念，有 K8s 部署经验更佳
- **对象存储**：S3 / MinIO / OBS / OSS 任一；熟悉预签名 URL、策略模式
- **监控**：Prometheus + OpenTelemetry；**日志**：zap / zerolog

### 工程规范

- **Git** 协作、**JWT** / **API Key** 认证、`golint` / `gofmt` 代码规范
