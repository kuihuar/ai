## 建议使用方式

1. 先过 01~04，覆盖原理 + 查询（面试占比最高）
2. 05~06 结合你项目里的「慢查询 / 导入 / 聚合」各准备 1 个案例

4. 模拟时严格：**问题 → 口述 → 等追问 → 展开知识点**

## 2 分钟开场模板（口述）

> Elasticsearch 是基于 Lucene 的分布式搜索与分析引擎，擅长全文检索、复杂过滤和聚合，和 MySQL 分工一般是：MySQL 管事务和权威数据，ES 管搜索和统计分析，接受近实时最终一致。核心机制是倒排索引加分片副本横向扩展，写入经 refresh 才可见所以是 NRT。工程上我会关注 mapping 设计、bool 里 filter 与 query 的拆分、深分页用 search_after，以及集群分片容量和 ILM 生命周期。
