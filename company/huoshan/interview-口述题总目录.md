# 火山面试口述题总目录（按 README 需求拆分）

本套题完全基于 `README.md` 当前需求整理，按能力模型拆分为 6 个专题。  
每题默认包含：**口述主答（60~120 秒）+ 高频追问 + 回答要点**。

## 文件目录

1. `interview-01-go-python-项目架构口述.md`  
   重点：Go/Python 分工、架构分层、接口契约、发布回滚。

2. `interview-02-llm-rag-工程化口述.md`  
   重点：RAG 数据链路、召回策略、评估体系、成本与稳定性权衡。

3. `interview-03-微服务与RPC接口设计口述.md`  
   重点：微服务边界、gRPC/Kitex、幂等、超时重试、版本治理。

4. `interview-04-数据库缓存与高并发口述.md`  
   重点：MySQL/Redis/ES 分工、一致性、高并发读写、性能优化。

5. `interview-05-稳定性与线上排障口述.md`  
   重点：SLA、限流熔断降级、故障定位、复盘闭环、容量治理。

6. `interview-06-工程素养与协作沟通口述.md`  
   重点：Git/测试/CI-CD、自驱协作、客户沟通、产品意识。

## 推荐练习顺序

- 第 1 轮：先练 `01 + 02 + 05`（最贴岗位核心）。
- 第 2 轮：补 `03 + 04`（工程细节与系统设计深度）。
- 第 3 轮：收尾 `06`（软技能与协作表达）。

## 统一答题模板（建议背熟）

> 背景（业务与规模） -> 挑战（瓶颈/风险） -> 方案（架构与策略） -> 权衡（为什么这么选） -> 结果（指标） -> 复盘（可改进项）
