# 火山岗位需求文档（后端研发）

## 1. 岗位定位

该岗位面向内容业务中的复杂 Agent 场景，核心目标是建设稳定、可扩展的后端服务体系，支撑 Agent 应用与数据产品持续迭代。

## 2. 岗位职责

### 2.1 后端服务设计与研发

- 参与复杂 Agent 核心后端服务的设计与开发。
- 使用 Go 和 Python 构建稳定、可扩展的微服务体系。
- 支撑 Agent 应用与数据产品在生产环境稳定运行。

### 2.2 LLM 应用工程化落地

- 与算法、产品团队紧密协作，将大模型能力工程化落地。
- 重点能力包括：RAG、观点提炼、内容生成等。
- 重点场景包括：事件库、自定义报告等业务模块。

### 2.3 稳定性与性能保障

- 负责服务性能分析与优化。
- 处理线上问题，推动故障复盘与持续改进。
- 保障系统高可用与高响应性。

## 3. 任职资格

### 3.1 必备项

#### 3.1.1 编程语言

- 精通 Go 或 Python，并愿意在工作中同时使用两种语言。
- 具备扎实编程基础和良好代码风格。

#### 3.1.2 后端技术能力

- 熟悉微服务架构。
- 具备接口设计经验。
- 具备 RPC 调用实践（如 Kitex、gRPC）。
- 具备数据库与缓存的实际应用经验。

#### 3.1.3 系统设计能力

- 能独立完成复杂后端模块的设计与开发。
- 对高并发、高可用系统有实践理解。

#### 3.1.4 工程能力

- 熟悉 Git 工作流。
- 有单元测试习惯。
- 理解 CI/CD 流程。
- 具备较强的问题分析与解决能力。

#### 3.1.5 软技能与协作

- 具备较强自驱力、沟通协作能力和产品意识。
- 能主动思考并推动技术方案落地与迭代。
- 能直接与客户沟通问题，具备基础产品沟通能力。

### 3.2 加分项

#### 3.2.1 AI Agent 实践

- 熟悉 LangChain、LangGraph、Eino 等 Agent 框架。
- 有 RAG、多 Agent 协作、Function Calling 等实际项目经验。

#### 3.2.2 信息处理与检索经验

- 了解 Elasticsearch、规则引擎、文本处理等技术。
- 有舆情、搜索、推荐等相关领域经验者优先。

## 4. 核心技术关键词（用于面试准备）

- `Go` / `Python`
- 微服务、RPC（`Kitex` / `gRPC`）
- 数据库、缓存、高并发、高可用
- `RAG`、多 Agent、Function Calling
- Elasticsearch、规则引擎、文本处理

## 5. 面试准备重点建议

1. 准备 1~2 个「Go + Python 混合后端」项目案例，重点讲架构分层与接口设计。
2. 准备 1 个「LLM 能力工程化落地」案例，重点讲数据链路、召回策略、效果评估。
3. 准备 1 个「线上性能或稳定性问题」排障案例，按问题定位、方案选择、结果复盘表达。
